# Front 실행 가이드

## 설치 (Install)

```
yarn install
```

> 참고: 현재 프로젝트 경로는 `./front/platform`입니다. 위 경로는 문서에 명시된 대로 작성되었습니다.

## API 및 모델 생성

> API 서버를 실행되어 있어야 합니다.
>
> - spring open api 스펙을 정확하게 작성 하여야 합니다.

API 서버를 실행되었다면 아래 명령어 실행하여 api와 model을 생성합니다.

```
yarn orval-fix
```

## 실행

```
yarn start
```
